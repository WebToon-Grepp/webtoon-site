# Webtoon Site
webtoon-site는 Flask 기반의 웹 애플리케이션으로, 웹툰 관련 데이터를 시각화하고 사용자에게 제공하는 프론트엔드입니다. 이 애플리케이션은 웹툰 데이터를 기반으로 다양한 정보와 차트 등을 시각적으로 보여줍니다. 

- Flask 기반: Flask 프레임워크를 사용하여 웹 애플리케이션을 구축합니다.
- 사용자 인터페이스: 웹툰 데이터를 기반으로 한 다양한 정보와 차트를 제공하는 UI를 구현합니다.

## Commit Convention
webtoon-site의 커밋 메시지는 기능/모듈명과 세부 내용을 포함해 아래와 같은 형식으로 작성합니다. 이를 통해 각 기능이나 변경 사항을 쉽게 파악할 수 있습니다.

```
<기능/모듈명>:: <커밋 내용>
```

예시:
- site:: Flask 프로젝트 초기화
- site:: 웹툰 목록 페이지 구현
- site:: 웹툰 차트 시각화 기능 추가
- site:: 사용자 인터페이스 개선
